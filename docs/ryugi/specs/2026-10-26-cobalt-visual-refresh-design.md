# 前琰官网 · 钴蓝视觉升级设计

日期：2026-10-26　状态：待用户最终确认

## 1. 意图

现有 Ryugi 首页版（`qianyan-github`，`ryugi-edition`）的问题集中在两处，用户原话是「图标，配色」：

- **配色**：整站是深海军蓝 + 冰蓝点缀的同一种冷灰蓝，没有主色和光源；四个样式文件里写死了 436 个不同色值，没有统一色板。读起来"像 AI 生成的模板"。
- **图标**：平台架构和小图标是"圆角矩形 + 几根横线"的通用线框（`diagramIcon()`、`icon()`），三层看不出区别；箭头 `↗`、菜单 `☰` 直接用字符。

目标气质：**工业精致感、高级感，少 AI 味**。用户给的参考是 Sentry 首页（钴蓝光源、等距细线立体图、深→浅楼层节奏）和 Paymark（质感与光线）。用户确认方向以 Sentry 为主。

## 2. 目标 / 非目标 / 反目标

**目标**
- 建立一套钴蓝色板，以 CSS 自定义属性（token）定义一次，全站引用。
- 用等距（isometric）细线立体图替换现有的方框线图标和平台架构图。
- 页面节奏改成「深色首屏 → 蓝雾过渡 → 浅色正文楼层」。
- 中英文、响应式、键盘可用、reduced-motion 降级保持现有水平或更好。

**非目标**
- 不改信息架构、导航项、文案内容和业务边界（除了为新图形补的短标签）。
- 不新建详情页、客户案例页，不接入真实表单提交。
- 不换框架：仍是原生 HTML/CSS/JS、无构建、GitHub Pages 直出。

**反目标**（做到了也算失败）
- 大面积粗线图形、线条随缩放变粗：用户明确说"大的线形图形会显得不精致"。
- 标注文字压在图形外面、溢出图形边缘，看起来像出错。
- 深色到浅色的过渡发生在不到一屏的高度里，显得突兀。
- 新增任何未经核实的能力声明、客户、认证或效果数字（沿用《网站规划草案》的文案边界）。

## 3. 已定的设计决定（用户在画板上选定）

画板：`artboard`，id `qianyan-visual-refresh`，路径 `CablePilot/.ryugi/artifacts/artboard/qianyan-visual-refresh/`（不在 git 里；以下文字即为准）。

| 题 | 决定 | 画板 |
|---|---|---|
| q1 主色与光源 | **A 钴蓝光源** | `q1-a` |
| q2 图形语言 | **a 等距细线立体**，并要求缩小比例 | `q2-a` |
| q3 明暗节奏 | **a 深色首屏 → 浅色正文** | `q3-a` |
| q4 首屏插画比例 | **a 缩到约 62%** | `q4-a`（已修正标注溢出） |
| q6 平台楼层图形 | **a 约 62%，图下一行规格标签** | `q6-a` |
| q5 首屏→浅色过渡 | **a 首屏满一屏 + 约 400px 蓝雾过渡带** | `q5-a` |

### 3.1 色板（来自 `q1-a` / `q5-a`）

深色区：
- 底 `#04060c`，渐深 `#05081a`
- 主色钴蓝 `#2f55f4`，光源核心 `#2a4dff` → `#1733d6`
- 浅蓝强调 `#a9bdff`（标题强调词、深色区线稿 `#bccbff`）
- 正文 `#f2f4fb`，次要 `#9aa3bd`，标题弱化行 `#8c95b0`
- 细线 `rgba(190,205,255,.12)`，强细线 `rgba(210,220,255,.3)`
- 状态信号（在线/正常）`#5fe8b4`

浅色区：
- 底 `#eef1f8`，正文 `#0b1020`，次要 `#566079`，标题弱化行 `#8a93ab`
- 强调与线稿 `#2f55f4` / `#3a55d9`，细线 `rgba(10,20,60,.12)`，信号 `#12a876`

产品真实色（不属于品牌色，只用在设备示意上）：墨水屏纸白 `#e9ecf3`、墨水屏红 `#c8453a`。

主按钮：`linear-gradient(180deg,#5d86ff,#2f55f4)`，白字，圆角 4px。次按钮：1px 强细线描边。

### 3.2 首屏（`q4-a`）

- 高度至少一屏（`min-height:100svh`，桌面参考 800px）。
- 左侧文案：两枚等宽小标签（`工业现场数字化解决方案`、带信号方块的 `NFC · IoT · API`）、主标题两行（第一行弱化色，第二行白色，"可追溯"用浅蓝强调）、副标题、主次按钮。
- 右侧光源：以插画为中心的钴蓝径向光，向四周衰减到底色。
- 插画：三层等距平板（平台 → 网关 → 终端），终端层上立一块墨水屏标签，网关层上一个网关盒体；层间虚线连接、白色节点带光晕。整体缩到第一版的约 62%。
- 线条一律 1px，且不随缩放变粗（SVG 用 `vector-effect:non-scaling-stroke`）。
- 标注规则：
  - 贴在平板表面的等距标签只用短英文（`PLATFORM`、`EDGE`），必须完全落在所贴的边内。
  - 引线标注放在插画外侧（`E-INK TAG · NFC`、`LED · SUB-1G`、`API · MQTT → MES / EAM`），等宽 11px，不随插画缩放。
- 首屏底部现有的三条能力条（`hero-foot`）移出首屏，放进下面的蓝雾过渡带（见 3.3）。

### 3.3 蓝雾过渡带（`q5-a`）

- 首屏下方约 400px：背景从 `#05081a` 经 `#0c1a62`、`#2741c2`、`#8197ea`、`#dbe2f7` 过渡到 `#eef1f8`，中间叠一层横向铺开的钴蓝雾光。
- 雾里放**现有首屏的三条能力条**（用户确认，内容不变，只换位置和样式）：引语「从现场感知，到业务协同」+ 三项「智能终端与现场标识」「边缘部署与离线作业」「开放接口与系统集成」（英文沿用线上）。
- 版式参照画板 `q5-a` 的条带：引语作为第一格的等宽小标签，三项各占一格，白字，分隔线 `rgba(255,255,255,.22)`；原 `icon(0..2)` 小图标换成同语言的等距细线小图（约 32px，终端 / 网关 / 平台）。画板 `q5-a` 里放的是四个业务入口，以本条文字为准。
- 下一个楼层标题出现时，背景必须已经是浅色。

### 3.4 浅色楼层与图形（`q6-a`）

- 楼层标题两段式：弱化色一句 + 钴蓝强调一句（例：`连接现场，` + `融入你的业务系统。`），44px 左右，字距收紧。
- 平台三层（终端 / 网关与边缘 / 平台与集成）每格一幅等距细线图，约为第一版的 62%（显示高度约 210px）。
- 小尺寸图形**不放引线文字**。改为图下一行钴蓝等宽规格标签：`E-INK · LED · NFC`、`SUB-1G · BLE · LOCAL CACHE`、`ON-PREM · API · MQTT`。
- 浅色区线稿用钴蓝，面填充极淡（5%～16% 钴蓝透明度）。

## 4. 约束

- 静态站，`index.html` + `app.js` 渲染全部内容，GitHub Pages 从 `main` 根目录发布。改动后资源版本号要更新，避免旧缓存。
- 品牌 Logo 用原图 `qianyan-brand.png`，用 CSS 视窗裁出圆环，不重绘。
- 文案边界沿用 `网站规划草案.md`：示意要明确标注，不虚构客户和效果。
- 正文 ≥ 14px；功能性小字（标签、导航、按钮）≥ 11px；文字对比度达到 WCAG AA。
- `prefers-reduced-motion` 与窄屏要降级，现有降级行为不能退步。

## 5. 留给实现者的部分（我的判断，供确认）

以下用户没有逐项决定，按第 3 节的方向由实现者处理：

1. **样式结构**：新增一个 token 层（`:root` 自定义属性，深色与浅色两组作用域）和一个新版式样式文件，替代 `ryugi.css` 中的首屏构图；`studio.css` / `dark.css` 里与新色板冲突的颜色改为引用 token。新代码不再写死色值。是否把四个样式文件合并，由实现者视风险决定。
2. **其余楼层的明暗**：产品与方案、平台与集成、点检演示、交付与保障都用浅色；预约咨询改成深色钴蓝收尾带（与首屏呼应），页脚深色。
3. **产品与方案楼层**：保留现有的展开式列表和左侧展示面板；面板配色改为浅色版，四个业务的概念图改成同一等距细线语言（同样约 62%，同样不放引线文字）。
4. **点检演示楼层**：墨水屏设备示意保留真实三色（纸白 / 黑 / 红），设备外壳改成细线 + 浅面，不再用金属渐变和发光；状态按钮按钮化样式统一到新 token。
5. **字符图标**：`↗`、`☰`、`+`、`↓` 等字符换成内联 SVG 线形图标，1.4px 描边，与等距插画同一线条气质。
6. **动效**：首屏视差改为三层平板差速位移（每层最大 ±12px），过渡带不做视差；其余保留现有渐入。reduced-motion 下全部关闭。
7. **手机端**（≤ 640px）：首屏插画移到文案下方、宽度 100%，等距表面标签保留，外侧引线标注隐藏；蓝雾过渡带高度缩到约 280px，四个业务入口改为 2×2；平台三格改为纵向。
8. **英文版**：插画标注本身就是英文，中英文共用；楼层标题的两段式在英文里同样拆成"弱化句 + 强调句"。
9. **文案以线上 `app.js` 为准**：画板里的按钮文字、副标题、楼层正文只是示意，不照搬。线上的导航「方案咨询」、首屏「探索产品与方案 / 了解技术平台」、平台三格标题与正文都保持不变。只新增插画短标签和规格标签（`E-INK · LED · NFC` 等，均为已有能力的缩写）。
10. **首屏清理**：去掉设备 + 仪表盘 + 网关整幅场景、`decorate()` 插入的 `exhibit-side / exhibit-word / exhibit-spec`、`hero-edition`；保留 `hero-top` 眉标行（改用新 token）；「产品形态与界面示意」说明保留，放在插画右下角。
11. **蓝雾带能力条不可点击**：线上这三条是纯文字，保持不加链接。
12. **平台楼层保留滚动叙事**：保留 `system-stage` 吸顶与随滚动聚焦的三段结构（这是上一轮已确认的设计）。系统图重画成首屏同款的三层等距平板（缩到约 62%），当前段对应的平板描边加粗为 1.5px 钴蓝、其余层降低透明度；`↔` 箭头与 `platform-bottom` 三条说明保留，换新 token。
13. **吸顶导航随楼层换色**：在深色首屏与收尾带上保持深色半透明；滚动进入浅色楼层后切换为浅色半透明（`rgba(238,241,248,.86)` + 背景模糊，深色文字），用 IntersectionObserver 判断，过渡 200ms。

## 6. 完成标准

- 桌面 1440 / 1280、平板 834、手机 390 下，中英文各走一遍，没有溢出、重叠和横向滚动。
- 首屏到第一个浅色楼层之间，过渡高度不少于约 400px（桌面）。
- 插画所有文字都落在设计位置内，没有压出图形边缘。
- 全站色值只来自 token（允许设备示意的三色）。
- 截图与画板 `q4-a`、`q5-a`、`q6-a` 对照，由用户确认通过。
